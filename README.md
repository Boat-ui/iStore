# 🍏 iStore — Apple Products E-Commerce Website

A modern and responsive e-commerce website built for showcasing and selling Apple products online.

## 🚀 Features
- Clean and premium Apple-style UI
- Product listings with images
- Responsive design (mobile & desktop)
- Dynamic product rendering using JavaScript
- Easy-to-navigate layout
